# BUG-151: Faktúra nesedí s e-shopom o cent

**Nahlásil:** účtovníctvo
**Priorita:** stredná

Zákazník s objednávkou **2026-1033** reklamuje faktúru: v e-shope mal zľavu **9,19 €**, na faktúre je **9,18 €**.

Účtovníčka hovorí, že pri septembrovej uzávierke „pár faktúr nesedelo o cent“, ale nezapísala si ktoré. Myslí si, že sa to deje „len pri niektorých cenách“.

Faktúry generujeme z exportu e-shopu:

```bash
python -m faktura.importer data/objednavky-2026-09.csv
```

Čo vypočítal e-shop, je v `data/eshop-faktury-2026-09.csv`. E-shop počíta podľa `SPEC.md` a považujeme ho za správny.
